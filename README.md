\# Cricket Scoreboard Data Extraction



\## Overview

Computer Vision solution to extract bowling scoreboard data from video using EasyOCR.



\## Features

\- Processes bowling scoreboard video

\- Extracts player name, runs, wickets, overs

\- Outputs JSON and CSV files
